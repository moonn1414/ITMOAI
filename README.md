# ITMOAI

Прогнозирование риска увольнения сотрудников

Учебный ML-проект, выполненный в аспирантуре ИТМО. Цель проекта — проверить, можно ли по характеристикам сотрудника и условиям его работы оценить риск увольнения и выделить факторы, на которые стоит обратить внимание HR-команде.

> Проект выполнен на публичном датасете Kaggle в учебных целях. Это не production-модель и не инструмент для автоматического принятия кадровых решений.

## Бизнес-задача

Увольнение сотрудников создаёт для компании затраты на поиск, адаптацию и сохранение экспертизы. Задача проекта — построить модель бинарной классификации, которая по историческим данным оценивает вероятность увольнения, и проанализировать признаки, связанные с этим риском.

## Что сделано

- Сформулировал бизнес- и ML-постановку задачи: бинарная классификация по целевой переменной `Attrition`.
- Провёл EDA: проверил структуру и качество данных, изучил распределения и связи признаков, исключил константные и неинформативные поля.
- Подготовил данные: закодировал категориальные признаки, разделил выборку на train/test с фиксированным `random_state`.
- Построил baseline с `DummyClassifier`, затем сравнил его с `DecisionTreeClassifier` и `LogisticRegression`.
- Применил стандартизацию признаков для логистической регрессии и оценивал модели с помощью `accuracy`, `precision`, `recall`, `F1-score` и `classification report`.
- Обучил `RandomForestClassifier`, подобрал гиперпараметры через `GridSearchCV` и `Optuna` с кросс-валидацией.
- Визуализировал результаты поиска параметров и проанализировал значимость признаков через permutation importance.

## Результат

На этапе подбора параметров Random Forest с балансировкой классов модель достигла на тестовой выборке:

- Accuracy: **0.8129**
- F1-score: **0.4954**

Для этой задачи accuracy недостаточно: класс увольнений несбалансирован, поэтому отдельно смотрел на precision, recall и F1-score. Результаты интерпретируются как учебная проверка подхода, а не как готовое решение для внедрения.
